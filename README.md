# Автоматизация UI и API проверок Кинопоиска

Учебный дипломный проект на Python: проверка поиска на сайте Кинопоиска с помощью Selenium и запросов к API `api.kinopoisk.dev` с помощью requests. Тесты организованы через pytest, действия с интерфейсом вынесены в Page Object, шаги и результаты оформлены с помощью Allure.

Проект показывает работу с браузерной автоматизацией, HTTP-запросами и проверками ответов. API используется как отдельный источник данных о фильмах и актёрах; проект не подтверждает, что это внутренний API сайта Кинопоиска.

## Технологии

| Инструмент | Назначение |
| --- | --- |
| Python | Язык тестов и вспомогательных классов |
| pytest | Организация и запуск тестов, fixtures |
| Selenium WebDriver | Управление браузером в UI-тестах |
| requests | HTTP-запросы в API-тестах |
| Allure Pytest | Шаги, названия и результаты тестов |
| Page Object Model | Отделение действий с интерфейсом от сценариев |

## Сценарии

**UI:**

- Проверка заголовка главной страницы.
- Поиск фильма по названию.
- Поисковые запросы с годом, страной и жанром.

Запросы с годом, страной и жанром выполняются через общую строку поиска. Они не являются проверками отдельных фильтров каталога.

**API:**

- Получение фильма по ID.
- Поиск фильмов с параметрами года, жанра и рейтинга.
- Получение информации об актёре по ID.
- Поиск фильмов с участием актёра.
- Получение номинаций актёра.
- Негативная проверка запроса с номером серии вне допустимого диапазона.

## Подготовка

Для локального запуска нужны Python, Google Chrome и доступ к внешним сервисам. Проект запускался в окружении Python 3.13 на Windows. Для API-проверок необходим действующий ключ к используемому API.

Все команды ниже выполняются из корня проекта — папки с `pytest.ini` и `requirements.txt`.

```powershell
git clone https://github.com/kalyaminat/Diploma_work_QA.git
cd Diploma_work_QA
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Команды используют Python из `.venv` напрямую; активация окружения не требуется. Если проект уже скачан, начните с создания окружения в его корневой папке.

### Настройки API

Текущая реализация читает настройки из `config.py`: `main_url`, `url_api` и `api_key`. Для запуска API-тестов необходим собственный действующий API-ключ. В локальном файле config.py замените YOUR_API_KEY своим ключом.Укажите действующий ключ только в локальной копии. 

### Браузер

UI-тесты создают Chrome через `webdriver.Chrome()`. Selenium Manager может подготовить драйвер автоматически; для первоначальной загрузки нужен доступ к сети. В текущей реализации браузер запускается с видимым окном.

## Запуск тестов

Весь набор:

```powershell
.\.venv\Scripts\python.exe -m pytest
```

Только API:

```powershell
.\.venv\Scripts\python.exe -m pytest test/test_api.py
```

Только UI:

```powershell
.\.venv\Scripts\python.exe -m pytest test/test_ui.py
```

Один API-тест:

```powershell
.\.venv\Scripts\python.exe -m pytest test/test_api.py::test_get_movie_by_id -v
```

## Отчёт Allure

`pytest.ini` уже содержит `--alluredir=allure-files`: результаты запуска сохраняются в `allure-files`.

Для просмотра нужен отдельно установленный **Allure Report 2 CLI**. Пакет `allure-pytest` сам по себе не устанавливает эту утилиту. Инструкция: [установка Allure Report 2](https://allurereport.org/docs/v2/install/).

Быстрый просмотр:

```powershell
allure serve allure-files
```

Генерация отчёта и открытие:

```powershell
allure generate allure-files -o allure-report --clean
allure open allure-report
```

Перед независимым прогоном очистите старые результаты в `allure-files`, если не хотите объединять несколько запусков. Параметр `--clean` в команде генерации очищает папку HTML-отчёта, а не исходные результаты тестов.

## Ограничения и статус

Проект выполнен в рамках дипломной работы и прошёл проверку преподавателей на момент завершения обучения.

UI-локаторы соответствуют интерфейсу Кинопоиска на момент выполнения проекта. 

API-тесты подготовлены на основе Postman-коллекции. При доработке отдельно подтверждены успешные запуски тестов получения фильма по ID, информации об актёре и его номинаций. 

Тесты зависят от доступности внешних сервисов, действующего API-ключа, сетевых настроек и ограничений доступа.
Данные и порядок выдачи API могут изменяться.
